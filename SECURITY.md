# Reporting a vulnerability · Segnalare una vulnerabilità

**Ethical hackers welcome.** Try to attack Campanile: better that you find a weakness
today than an attacker during an emergency.

Please **don't open a public issue**. Use GitHub's private reporting: **Security →
Report a vulnerability** in this repository. Include the version (bottom of every
page), the steps to reproduce and what it allows. We'll answer as soon as we can and
credit you in the fix, if you like.

---

**Ethical hacker benvenuti.** Prova ad attaccare il Campanile: meglio che un punto debole
lo trovi tu oggi che un attaccante durante un'emergenza.

**Non aprire una issue pubblica.** Usa la segnalazione privata di GitHub: **Security →
Report a vulnerability** di questo repository. Indica la versione (in fondo a ogni
pagina), i passi per riprodurre il problema e cosa permette di fare. Rispondiamo il prima
possibile e ti diamo credito nella correzione, se lo desideri.

Threat model and existing defenses: [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md)
(in italiano: [docs/SICUREZZA.md](docs/SICUREZZA.md)). The limits we already know, published:
[docs/LIMITS.md](docs/LIMITS.md) (in italiano: [docs/LIMITI.md](docs/LIMITI.md)). There has been
no external audit yet. A new way around a known limit is still worth a report.
